WINBRO LIFESTYLE - RUN GUIDE

1. Install dependencies:
   npm install

2. Start server:
   npm start

3. Customer storefront (give this link to customers):
   http://localhost:3000/

4. Private admin login:
   http://localhost:3000/admin

5. Admin dashboard:
   http://localhost:3000/admin/dashboard

The old /admin.html and /admin-dashboard.html URLs are intentionally blocked.
Customers only receive the storefront with products, cart, checkout and order/payment options.
